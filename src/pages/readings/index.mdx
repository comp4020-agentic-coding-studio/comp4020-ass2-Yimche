# Readings

None of this is set as required reading. It is the field the course draws from:
the gallery it argues with, the repositories it holds up as examples, and the
reference you will reach for when a compositor will not behave. Read it the way
you rice, by following what interests you and crediting what you take.

## The gallery

[r/unixporn](https://reddit.com/r/unixporn) is the shop window, and the course
treats it as exactly that. Every setup on it was photographed to be seen rather
than assembled to get work done faster, which is the tension weeks 8 and 11
spend their time on. Read it as evidence, not as instruction.

## Where to start

[awesome-ricing](https://github.com/fosslife/awesome-ricing) is a curated index
of the tools, bars, launchers, and colour schemes the craft is built from. When
you do not yet know what to search for, start here and let the categories name
the pieces for you.

[direwolf-arch-rice](https://github.com/ibrahimbutt/direwolf-arch-rice) is one
setup documented well enough to reproduce. Read it as a worked example of the
thing this course asks you to produce: a rice someone else can rebuild from the
repository alone, with its sources credited.

## Reference

The Arch Wiki's [Eye candy](https://wiki.archlinux.org/title/Category:Eye_candy)
category is the reference the rest of the field quotes. When a guide tells you to
install a compositor or a theme engine, this is where you confirm what it
actually does before you paste the command.
